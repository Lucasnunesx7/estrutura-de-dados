📝 Desafio: Array de Alunos
O objetivo deste exercício foi criar uma estrutura de dados simples contendo uma lista de alunos e, em seguida, acessar propriedades específicas utilizando os índices do array.

 ⚙️ Requisitos do Exercício
1. Criar um array chamado `alunos` com 5 objetos.
2. Cada objeto deve conter: `nome`, `idade` e `disciplinaPreferida`.
3. Acessar e exibir o nome do primeiro aluno.
4. Acessar e exibir a disciplina preferida do último aluno.
